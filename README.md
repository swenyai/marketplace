# SWEny Workflow Marketplace

Discover, share, and create AI-powered workflows for [SWEny](https://github.com/swenyai/sweny).

**[Browse workflows at marketplace.sweny.ai](https://marketplace.sweny.ai)**

## What is this?

SWEny workflows are YAML-defined DAGs that orchestrate AI agents to perform software engineering tasks — triaging alerts, reviewing PRs, auditing security, generating docs, and more.

This repo is the community hub:
- **Browse** workflows with interactive DAG visualization
- **Create** workflows using AI — describe what you want in plain English
- **Share** your workflows with the community via PR
